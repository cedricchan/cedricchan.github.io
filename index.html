2024 · Tech lead · team of 3 · first project on ECS

Zero downtime migration of the agent credential store

Every container instance fetches task credentials from one store. It lived in a write-expensive ledger database that had become a cost and scaling risk. I led a team of three to move it to DynamoDB in every region, including isolated partitions, without a moment of downtime.

Leading it: a team of three on my first project in a new organization, the release and test plan the rollout ran on, and the security review owned end to end with the application security team.

How
  • Wrote the decision log and a "write diet" that cut write volume before the move, then the low level design, the prototype, and the release and test plan.
  • Dual write, then dual read, then single path, one region at a time, with each phase switchable by configuration so rollback never needed a deployment.
  • Owned the security review with the application security team, added point in time recovery, TTL, deletion protection, and throttling alarms, then removed the legacy path entirely.

    How I lead

    Four habits, each with a receipt

    Contract first

    Settle the interface between teams before the code. The credential delivery contract with a partner platform team and the daemon validation contract with the federation team both shipped without a redesign.

    Decision logs, not meetings

    Every project I lead carries a written decision log with owners and dates. It is how four partner teams stayed aligned through the lifecycle migration, and how a manager could report status without asking me.

    Reversible by default

    Phased rollouts behind configuration: three phases for the credential migration, six waves for the lifecycle migration, feature flags for every placement strategy. Rollback never needed a deployment.

    Grow the people

    Three engineers mentored, one promoted in 2026. Two interns shipped production grade projects. More than fifty interview loops, Bar Raiser in training, and a GenAI enablement program the whole team adopted.
